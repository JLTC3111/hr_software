Use `src/components/HrMascot.jsx` to render it; the component accepts `size`, `className`, and standard image props. Supply meaningful alternative text if it conveys information; the default is decorative.

Generated with the built-in ImageGen tool from the first blue HR penguin in the supplied `Chibi_HR_and_Contract_Mascots.jpg` style guide. The file retains its generated transparency. Only mascot artwork is prepared for the chatbot.
